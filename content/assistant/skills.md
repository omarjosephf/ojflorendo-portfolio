# OJ's skills and capabilities

## Programming languages, frameworks and web development skills

The programming languages and frameworks OJ works with are Python, TypeScript,
JavaScript, HTML, and CSS, with React and Next.js as his main web frameworks. He
builds responsive, accessible interfaces and practical applications on a
maintainable technical foundation.

His web development skills include front-end implementation with React and
Next.js, TypeScript in strict mode, component and design-token systems,
accessibility-conscious implementation, technical SEO foundations, automated
testing with Vitest and Playwright, and technical documentation. On the Python
side he has built a deployed backend service with FastAPI, containerised it with
Docker, and shipped it to Fly.io with continuous integration through GitHub
Actions.

He does not describe himself as an expert or a master in any of these. He is a
final-year Computing and IT student with practical experience, and his published
projects are the evidence for what he can actually build.

## AI and machine learning skills, and AI-assisted product development

OJ's AI skills cover narrow AI assistant prototypes, prompt and knowledge-workflow
design, AI-assisted research workflows, content workflows, small automation
prototypes, and human-reviewed AI-assisted engineering. He has delivered
professional training in prompt engineering and in AI and machine-learning
fundamentals.

Specific AI techniques he has built with rather than only read about:
retrieval-augmented generation over a document corpus, local text embeddings
running through ONNX, vector similarity search with NumPy, verified citations
computed against supplied documents, refusal behaviour for questions a corpus
cannot answer, and evaluation sets that score answer quality reproducibly. He has
worked with the Anthropic API and Claude models in a deployed, cost-controlled
production service.

His approach to AI is deliberately cautious: he uses it as a tool for research,
prototyping, implementation, and review, tests the output, and remains
accountable for the result rather than presenting AI work as self-verifying.
