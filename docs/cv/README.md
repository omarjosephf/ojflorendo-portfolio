## Review and update workflow

1. Update the DOCX using verified, owner-approved information only.
2. Scrub author and personal metadata.
3. Render every DOCX page and inspect it at full size.
4. Export the PDF, render every PDF page, and compare it with the reviewed DOCX output.
5. Scan both files for private data, secrets, local paths, broken links, and unsupported claims.
6. Update the hashes below.
7. Run the repository quality gate and obtain explicit publication approval.
